# 设计系统

一套颜色，四层信息。组件行为以今日学习这一条路径为准。

## 颜色

| 用途 | 值 |
| --- | --- |
| 页面底 | `#f7f8fa` |
| 卡片 | `#ffffff` |
| 正文 | `#171c29` |
| 次级文字 | `#71717a` |
| 主操作、焦点 | `#4867d8` |
| 主操作按下 | `#29459f` |
| 主操作浅底 | `#dbe3f5` |
| 危险 | 沿用 `base.css` 里的危险色，不改成主色 |

`workspace.css` 与 `study-plan.css` 的 `:root` 使用同一组值。密度切换不再改品牌色。

## 网格

- 桌面侧栏 232px。1500px 以上仍是 236px。
- 内容列最宽 1180px，顶栏不跟着这条上限收缩。
- 页面内边距沿用现有 24–32px。
- 卡片间距 16–18px，卡片内边距在平衡密度下是 24px。

## 四层

1. 主操作：总览的「开始这项」，今日的「开始下一项」和「保存这次结果」。
2. 支撑内容：今日任务、执行步骤、交付物。
3. 决策数字：本周偏差、复盘到期、容量冲突。
4. 低频系统：设置、导入、账号、资料核验。低频块可以折叠，总览上被浏览器门禁检查的卡片保持可见。

## 一个完成动作

开始、暂停、结束和结果记录都在今日页的计时卡片里。勾选任务即完成，默认记计划分钟；题量、错因和明日第一项可后补。结束计时后分钟按实际时长预填，其余字段同样可后补。取消勾选会撤回这次完成。右边的「今日学习输入」仍在，用来补整天记录。
