# 页面规范

十条路由都还在。下面只写这一轮改变后的主要动作。

| 路由 | 打开后先看到 | 主动作 |
| --- | --- | --- |
| `#dashboard` | 今天的第一项和唯一时长 | 开始这项，进入今日并计时 |
| `#today` | 下一项、容量提示、计时 | 开始、暂停、结束并记录一次 |
| `#week` | 七天计划 | 锁定任务在重排后保留 |
| `#foundation` | 阶段与资料 | 只读核验，不在这里记结果 |
| `#syllabus` | 考点与五态 | 点击仍在未开始、需复盘、已掌握之间切换 |
| `#records` | 每日记录 | 保留原来的编辑和导出 |
| `#review` | 到期复盘队列，然后才是本周数字 | 先处理到期项 |
| `#scores` | 模考趋势 | 成绩和错因仍按原来的表单保存 |
| `#resources` | 当前科目资料 | 不新增推荐流 |
| `#settings` | 时间预算和目标 | 改科目时仍要确认，不删除已完成记录 |

手机底栏顺序是总览、今日、复盘、计划、设置，再加上更多。设置本身是主标签，打开设置时「更多」不是当前页。
