# 第二轮变更说明

日期：2026-10-10。范围只覆盖学习闭环、同一套颜色和计划可恢复。没有改数据库迁移，没有推送，没有部署。

## 已改

- 任务正文不再把大纲里的「90 分钟分步」拼进计划。首页时长只显示排进去的分钟，例如 `125m`。
- 工作台和计划页的主色收到同一套蓝：`#4867d8`，浅底 `#dbe3f5`，页面底 `#f7f8fa`。危险色仍用原来的红色，不拿来当品牌色。
- 今日只保留一个计时器。结束计时后，同一张卡片里填写有效分钟、题量、错因和明日第一项，保存一次。45 分钟倒计时已去掉。
- 计划分钟超过当天可用时间 15 分钟以上时，今日页写出差额，并说明不会悄悄缩短已锁定任务。
- 重新生成今日计划前会留下上一版任务。`恢复上一版` 只退回这一天，最多保留 20 版。
- 复盘页把间隔队列放在本周数字前面。
- 在输入框里按 Ctrl 或 Cmd + K 不再抢走焦点。命令面板已经打开时，同一快捷键仍可关闭。
- 考点行在原有「未开始 / 需复盘 / 已掌握」旁边增加五态显示：未开始、学习中、巩固中、已学完、较稳定。存储值仍是 0、1、2。
- 桌面侧栏从 216px 调到 232px。内容列上限维持 1180px。

## 后来补上的排程

- `generateDailyPlan` 只负责排序和取舍。`createDailyTasks` 仍生成任务正文、科目和分钟。适配在 `src/domain/capacity-daily-plan.js`。锁定任务和英语不断档任务会留在结果里。未锁定任务超出剩余时间时仍可能被缩短，锁定分钟不会。
- 没有学习记录的新用户不会被算成连续缺勤 7 天。恢复计划只在已经有过学习、随后连续缺勤时出现。
- domain gzip 上限从 16 KB 调到 18 KB。接入后实测 17.16 KB。

## 故意没改

- 没有把 `src/core/router.js`、`src/core/state-manager.js` 或 `src/infrastructure/sync-service.js` 接进 `app.js`。生产路由、状态和同步仍各只有这一处。
- 没有新增错题表或会话表。错题、会话和计划版本都在本机状态和云端快照允许字段里。
- 没有勾选 `PLAN.md` 里尚未逐项验收的复选框。
