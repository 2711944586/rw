# 学习流程

一条路径：目标 → 今日计划 → 计时 → 一次结果 → 错题 → 复盘 → 需要时重排。

1. 设置里的目标决定科目。改科目会先确认。已完成的周计划不删。
2. 总览只展示下一项和排定分钟。点「开始这项」进入今日并开始计时。
3. 今日也可以点「开始下一项」，或勾选任务直接完成。完成默认记计划分钟，错因和明日第一项可后补。
4. 结束计时时，分钟按实际计时预填，最多 240。题量、错因和明日第一项可后补。有错因时记一条错题。
5. 复盘页先列出到期项。
6. 重新生成今日计划前要确认差异。锁定和已完成的项保留。确认后可以恢复上一版。
7. 计划总分钟比可用时间多出 15 分钟以上时，页面写明差额。已锁定任务保持原时长。

AI 辅助默认关闭，只在本机根据已有错题给一句提示，不上传。
